自動返信

自動返信機能を使用すると、サーバーのお問い合わせなどを自動化でき、サーバーをより強化できます。

自動返信を作成する

自動返信は、以下のコマンドで作成できます。

一行のみの場合: /autoreply create

複数行の場合: /autoreply form

「条件」、「反応するワード」が含まれたメッセージが送信されると、自動で指定したメッセージが返信されます。

自動返信を削除する

自動返信は以下のコマンドで削除できます。

/autoreply delete

※「条件」、「反応するワード」などを指定して削除する必要があります。

自動返信をリスト化する

自動返信は以下のコマンドでリスト化できます。

/autoreply list

自動返信で使える変数

自動返信のメッセージ内に以下の文字列を入力すると、自動で置き換わります。

ランダムな数字と選択を使用する

ランダムな数字は、{random:最小数~最大数}で挿入でき、

ランダムな選択は、{choice:１つ目|２つ目|３つ目}という形式で挿入できます。
各項目は|で区切る必要があります。

自動返信で埋め込みを使用する

自動返信で埋め込みを使用するには、以下の文字列を自動返信作成時の結果に入力する必要があります。

{embed:title=タイトル,description=説明,image=画像url,thumbnail=サムネイル画像url,color=数字の色(16711680),footer=フッターテキスト,footer_icon=フッターアイコンURL,author=ユーザーテキスト,author_icon=ユーザーアイコンURL}
